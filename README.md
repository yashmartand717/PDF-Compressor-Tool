# PDF Compressor

A Streamlit tool that shrinks large, image-heavy PDFs (such as textbooks) by downsampling and re-encoding the embedded images. The text stays the same.

## Features
- Upload a PDF and download the compressed version
- Shows the size before and after compression

## Tech stack
Python · Streamlit · PyMuPDF · Pillow

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
